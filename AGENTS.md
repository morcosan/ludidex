# Project instructions

- never run app build, skip this step
- never run prettier, just use lint pnpm command
- always use pnpm
- never open your internal browser
- always check if existing storybook story need updates after changing components
- all external scripts you temporarily use must be placed inside project root
- avoid adding useless shrink-0
- if an arrow function has multiple lines, always use {}
- use only linux commands, no windows cmd
- use "char" instead of "character" in short arrow functions
